# Campus Concierge

### Your campus life, sorted.

Campus Concierge is a student-focused platform designed to make fresher life easier by bringing essential campus services into one place.

## About the Project

Campus Concierge – Fresher Survival Hub helps students discover and access useful services around their campus.

The platform includes:

- Mess services
- Laundry services
- Room cleaning and housekeeping
- PG and hostel discovery
- Cafes and restaurants
- Roommate finder
- Fresher Pass
- Student bookings
- Vendor management portal

## Main Features

### Student Side

Students can:

- Register and log in
- Explore campus services
- Search and filter vendors
- View vendor details
- Book services
- Track bookings
- Use Fresher Pass plans
- Find compatible roommates
- Manage their profile

### Vendor Side

Vendors can:

- Register and log in
- Manage their business profile
- Add and manage services
- Manage availability
- Receive student bookings
- Accept or reject orders
- Update order status
- Track completed orders
- View earnings

## Roommate Finder

The roommate feature helps students discover compatible roommates based on preferences such as:

- Sleep schedule
- Cleanliness
- Noise preference
- Food preference
- Lifestyle

## Fresher Pass

Campus Concierge provides multiple Fresher Pass plans with different benefits and offers.

## Technology

The frontend prototype is built using:

- Next.js
- React
- JavaScript
- Tailwind CSS
- Lucide React

The initial prototype uses frontend/local storage functionality.

A backend, database, authentication system and payment integration can be connected later.
